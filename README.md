# profile

Personal portfolio and CV site for **Sam Frederick Gorman-Hailey**, a full-stack developer
with a background in video production.

It's a hand-written static site — plain HTML, CSS and vanilla JavaScript, no
framework and no build step. One page (`index.html`) with an intro, skills,
projects and contact sections. The animated background is a small three.js scene
that renders a 3D model of my initials "SFGH".

## three.js
three.js is loaded from a CDN (see the import map in `index.html`), so you need
an internet connection.
